3. QUY TRÌNH VẬN HÀNH GAME (GAMEFLOW SEQUENCE)1.Mở phòng & Quét QR:MC khởi tạo room.MC mở giao diện /mc, bấm "Khởi tạo Vòng 1". Mã QR được sinh ra chứa URL: https://<domain>/play?room=CLB30. Thành viên quét QR qua Zalo để truy cập.2.Gửi đáp án (Async Task):Thành viên nhập số từ 0 - 100.Thành viên nhập Tên & Số chọn $\rightarrow$ Socket Gateway nhận Request $\rightarrow$ Đẩy ngay Event PLAYER_SUBMITTED vào RabbitMQ Queue $\rightarrow$ Báo Zalo Client "Đã nhận đáp án!".3.Xử lý Queue & Lưu Redis:Worker thực thi công việc.Worker tiêu thụ Message từ RabbitMQ $\rightarrow$ Lưu thông tin người chơi và con số vào Redis Hash tương ứng với Vòng đấu.4.Khóa sổ & Tính kết quả:MC bấm Chốt sổ.MC bấm "Tính Kết Quả" $\rightarrow$ Gateway bắn Event vào Queue $\rightarrow$ Worker kéo toàn bộ Submissions từ Redis $\rightarrow$ Tính $2/3 \times \text{AVERAGE}$ $\rightarrow$ Xác định Winner $\rightarrow$ Lưu kết quả vào Redis & Emit tới tất cả các máy.4. BẢN TRỪU TƯỢNG HÓA DATA MODEL (DATA MODELS SPECIFICATION)Dưới đây là thiết kế Schema cho Redis Data Store và Format Message truyền qua RabbitMQ.4.1. Entity Schema (TypeScript Interfaces)A. User & Session ModelTypeScriptinterface PlayerSession {
  playerId: string;       // Unique ID (UUIDv4 hoặc Generated Device Fingerprint)
  socketId: string;       // ID kết nối Socket.io hiện tại
  name: string;           // Biệt danh người chơi
  isOnline: boolean;      // Trạng thái kết nối
  joinedAt: number;       // Timestamp gia nhập phòng
}
B. Game Round ModelTypeScriptinterface PlayerGuess {
  playerId: string;
  playerName: string;
  guessNumber: number;   // Con số chọn (0.00 - 100.00)
  submittedAt: number;   // Timestamp nộp bài
}

interface RoundResult {
  totalPlayers: number;  // Tổng số người tham gia nộp bài
  average: number;       // Giá trị trung bình cộng
  target: number;        // Target = Average * (2/3)
  winner: {
    playerId: string;
    playerName: string;
    guessNumber: number;
    difference: number;  // Độ lệch so với Target (|Guess - Target|)
  };
  calculatedAt: number;
}

enum RoundStatus {
  WAITING = 'WAITING',   // Đang chờ người chơi gửi số
  LOCKED = 'LOCKED',     // Hết giờ/Đã khóa sổ, đang tính toán
  ENDED = 'ENDED'        // Đã có kết quả
}

interface GameRound {
  roundId: number;       // Vòng 1, Vòng 2, Vòng 3...
  status: RoundStatus;
  result: RoundResult | null;
}

5. THUẬT TOÁN TÍNH TOÁN CỦA WORKER (WORKER LOGIC)Khi Worker nhận Message CALCULATE_ROUND_RESULT từ RabbitMQ:PlaintextStep 1: Đọc tất cả entries từ Redis Hash `room:{roomId}:round:{roundId}:guesses`.
Step 2: Nếu (length == 0) -> Return No Submissions.
Step 3: Tính Sum = Sum + guessNumber.
Step 4: Average = Sum / length.
Step 5: Target = Average * (2 / 3).
Step 6: Duyệt qua danh sách, tìm Player có |guessNumber - Target| nhỏ nhất.
Step 7: Ghi RoundResult vào Redis Key `room:{roomId}:round:{roundId}:result`.
Step 8: Bắn Socket Event `ROUND_RESULT_READY` về cho Socket Gateway để gửi tới Zalo Clients & MC View.
